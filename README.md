# <!--劇団ナビ-->

## サイト概要


### サイトテーマ
劇団と劇団員をつなぎ、募集・応募・交流ができるコミュニティサイト
​
### テーマを選んだ理由

私は以前から演劇やミュージカルに興味があり、劇団について調べる機会がありました。その中で、劇団員を募集している情報やオーディション情報がさまざまなSNSやホームページに分散しており、希望する劇団を探しづらいと感じました。
そこで、劇団が募集情報を一元管理でき、応募者は条件に合った劇団を簡単に検索・応募できるサービスがあれば、双方にとって便利になると考え、このテーマを選びました。
​
### ターゲットユーザ

劇団が新しい劇団員や出演者を募集したい時
劇団やミュージカルへ出演したい人
新しい劇団を探している演劇経験者
​
### 主な利用シーン

劇団が新しい劇団員や出演者を募集したい時
劇団への入団先や出演先を探したい時
​オーディション情報を探したい時
